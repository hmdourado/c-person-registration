# C Struct, Union & Enum — Person Registration

A console-based person registration system developed in C
to practice structured data modeling and fundamental
programming concepts.

## Concepts

- `struct`
- `typedef`
- `union`
- `enum`
- Arrays of structures
- String manipulation
- Input handling
- Conditional logic
- Iteration

## Features

- Register multiple people
- Store personal information
- Handle Brazilian and foreign documents
- Use `union` to represent different document types
- Format and display registered information

## Technologies

- C
- GCC

## Purpose

Academic project developed as part of my Computer Engineering
studies at UTFPR.
